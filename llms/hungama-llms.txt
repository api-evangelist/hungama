# Hungama.com LLM Access Policy

> Hungama.com is a digital entertainment platform offering video-on-demand, series, movies, podcasts, and audio stories.  
> This file defines how AI systems, LLMs, and data crawlers may interact with and reference Hungama content responsibly.

## ⚙️ General AI Access Policy

| Permission Type | Status | Description |
|------------------|---------|-------------|
| Crawl & Index | ✅ Allowed | AI crawlers may access and index public pages. |
| Summarization | ✅ Allowed | Summaries up to 3 sentences are permitted. |
| Embedding | ✅ Allowed | Contextual embeddings for search/chat allowed. |
| Link Previews | ✅ Allowed | Snippets and link cards allowed. |
| Fine-tuning / Training | ❌ Disallowed | Not permitted without written consent. |
| Republishing | ❌ Disallowed | No verbatim reproduction. |
| Commercial Use | ❌ Disallowed | Must obtain license/approval. |
| Attribution Required | ✅ Yes | Use format: “Source: Hungama.com” |

## ✅ Allowed AI Usage Scenarios

AI systems (ChatGPT, Claude, Perplexity, Gemini, etc.) **MAY**:
- Discover and link to Hungama.com public pages.  
- Generate brief summaries (≤3 sentences).  
- Show rich previews of shows, movies, or podcast titles.  
- Reference show titles and metadata for discovery purposes.  

AI systems **MAY NOT**:
- Extract or store full transcripts, metadata, or video/audio content.  
- Train or fine-tune models on Hungama data.  
- Reproduce full reviews, episodes, or user data.  

**Example Allowed:**  
> “Watch *Ratri Ke Yatri* streaming on Hungama.com – an Indian anthology web series.”

**Example Not Allowed:**  
> “Here’s the full transcript of Episode 2 from *Ratri Ke Yatri*, sourced from Hungama.com.”
